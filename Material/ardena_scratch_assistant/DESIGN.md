## Brand & Style

This design system marries the structured technological trust of enterprise AI with the sensory, tactile, and playful world of Scratch 3 visual block programming. Designed specifically for primary school students (SD / ages 7–12), the interface removes intimidation from coding through cheerful modularity, tactile physical metaphors, and friendly guidance.

### Brand Personality
- **Playful & Inviting:** Warm, energetic, and forgiving. Failure is framed as playful debugging.
- **Approachable Tech:** Complex logic transformed into chunky, snap-together puzzle blocks with rounded geometries.
- **Supportive Companion:** The AI acts as an encouraging coding buddy rather than a formal instructor.

### Aesthetic Style
- **Playful Tactile Blocks:** Deeply inspired by Scratch 3's block-snapping language and kid-centric educational software. Features springy micro-interactions, distinct category-coded badges, raised button bevels (subtle bottom borders mimicking physical blocks), and clean backdrop stages.
- **Kid-Safe Ergonomics:** Oversized interactive touch targets (minimum 48×48px), high contrast readability, and intuitive visual cues that bypass complex text comprehension.

## Colors

The palette directly anchors to the standard Scratch 3 color-coded block taxonomy, making cognitive connections instantaneous for young coders.

### Functional Palette Roles
- **Primary (`#4C97FF` - Motion Blue):** Drives primary navigation, active state accents, system header branding, and the student's message bubbles.
- **Secondary (`#9966FF` - Looks Purple):** Represents AI companion guidance, hint callouts, and speech bubble identities.
- **Tertiary (`#FFBF00` - Events Yellow):** Reserved for primary execution triggers—most notably the Start / "Green Flag" equivalents and key calls-to-action.
- **Neutral (`#2E3C54`):** Soft ink slate providing high legibility against bright backgrounds without harsh pure-black contrast.

### Specialized Scratch Categorical Colors
- **Sound Pink (`#CF63CF`):** Audio recorder, microphone input toggles, and sound debugging.
- **Control Orange (`#FFAB19`):** Alerts, warning notices, loops, and conditional feedback.
- **Operators Green (`#59C059`):** Online status indicators, successful photo snapshot uploads, and validation badges.
- **Canvas Stages (`#F9F9F9` & `#E9F1FC`):** Provide a soft, low-glare workboard environment reminiscent of the Scratch project stage.

## Typography

Typography prioritizes high legibility, open counters, rounded terminal stroke structures, and instant character discrimination for young students.

- **Primary Font Family:** **Nunito Sans** with rounded curves and bold weights ensures effortless readability for early readers.
- **Hierarchy Structure:** Headers and action labels use heavier weights (700 and 800) to create clear scannability. Body text runs slightly larger than conventional enterprise software (standard baseline `16px` to `18px`) to minimize cognitive load on tablet devices and desktop screens alike.
- **Clarity Standards:** All code blocks, keyword chips, and inline block references mirror Scratch's native capitalization and bold visual emphasis.

## Layout & Spacing

The layout is built upon a child-friendly fluid grid designed to accommodate standard classroom Chromebooks, iPads, and mobile smartphones.

### Layout Model
- **Container Structure:** Standard desktop views feature a 3-part layout:
  1. Compact persistent top navigation header with large accessibility utilities (text zoom, audio cue toggles).
  2. Central conversational workspace scroll container framed like a Scratch Stage preview.
  3. Floating or docked oversized interactive media action bar at the base.
- **Rhythm & Safe Touch Areas:** Component spacing leverages an 8px base rhythm. Outer padding provides generous buffer space (`1.5rem` desktop, `1rem` mobile) to prevent accidental edge misclicks. Minimum interaction target dimensions for touch surfaces are rigidly kept at `48px` height and width.

## Elevation & Depth

Rather than relying on abstract blurred shadows, visual depth reflects physical "puzzle block" mechanics:

- **Tactile Chamfer & Drop-Offset:** Surfaces emulate Scratch blocks with a solid vertical drop offset (`box-shadow: 0 4px 0 rgba(0, 0, 0, 0.15)` or matching darker hue borders on the bottom edge).
- **Surface Elevation Hierarchy:**
  - **Level 0 (Stage Ground):** The soft canvas backdrop (`#E9F1FC` / `#F9F9F9`).
  - **Level 1 (Chat Cards & Stage Panels):** Crisp white containers (`#FFFFFF`) with 2px borders (`rgba(0, 77, 187, 0.08)`) and gentle ambient diffusion.
  - **Level 2 (Interactive Puzzle Blocks & Quick Chips):** Chunky colored cards featuring physical 3px bottom shelves. On `:hover`, blocks elevate slightly; on `:active`, they translate downward by 2px with shadow reduction, delivering a satisfying mechanical click response.
  - **Level 3 (Modal Overlays & Popovers):** High-priority tooltips, image upload previews, and camera viewers with backdrop blur and soft contrasting scrims.

## Shapes

The shape system adopts smooth, organic curves inspired by interlocking Scratch puzzle blocks. 

- **Base Radius (Roundedness 2):** Inputs, prompt tiles, and standard cards employ `0.5rem` to `1rem` radius.
- **Interactive Buttons & Chips:** Quick-action chips and primary interaction capsules adopt full-pill forms (`9999px`) or `1.5rem` corners to eliminate sharp, clinical edges.
- **Puzzle Notches:** Specialized dialogue bubbles feature an iconic Scratch-inspired speech notch or snap tab on the top-left corner, reinforcing the feeling of physical code blocks snapping together.

## Components

### Buttons
- **Primary "Event" Button (Green Flag / Send):** Styled in Events Yellow (`#FFBF00`) with bold text, an icon badge, and a darker bottom border (`#D9A300`). Depresses when pressed with a tactile bounce.
- **Media Action Circles:**
  - **Voice Input:** 52px circle in Sound Pink (`#CF63CF`) featuring an animated ripple state when actively listening.
  - **Image / Camera Input:** 52px circle in Operators Green (`#59C059`) for snapping photos of physical Scratch screens.
- **Touch Target:** No interactive button is smaller than 48px in height.

### Chat Bubbles
- **Ardena (AI Assistant):**
  - Crisp white container framed by a 2px Looks Purple accent border (`#9966FF`).
  - Anchored with the Ardena round avatar emblem on the top left.
  - Inline block callouts inside answers render as miniature Scratch block tags (e.g., Motion tags highlighted in `#4C97FF` with white text).
- **Student (User):**
  - Bubble filled in Motion Blue (`#4C97FF`) with bold white text and a rounded puzzle-tail edge aligned to the right.

### Quick Action Chips (Question Starters)
- Floating pill-shaped buttons containing popular child queries (e.g., *"How to make the Scratch Cat walk?"*).
- Outlined in Control Orange or Motion Blue with clean pastel fills. Features a bouncy `:hover` micro-animation.

### Input Bar
- Stitched composite bar containing the expandable text field with `28px` rounded corners, accompanied by docked Voice, Image, and Send triggers.
- Accompanied by a collapsible drag-and-drop thumbnail preview tray when code screenshots are staged for analysis.

### Thinking Indicator (AI Typing State)
- Three springy, bouncing dots colored in Looks Purple (`#9966FF`), enclosed within a soft cloud-like bubble mimicking Scratch thinking sprites.
