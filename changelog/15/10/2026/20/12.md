## Rincian Perbaikan Teknis
1. **Perbaikan cURL Multipart pada `HttpClient.php`:**
   - Menambahkan parameter `$isMultipart = false` pada `HttpClient::request()` dan mengaktifkannya secara eksplisit pada `HttpClient::postMultipart()`.
   - Menghentikan proses `json_encode($body)` yang tidak disengaja terhadap array multipart berisi objek `\CURLFile`.
   - Memastikan cURL PHP menghasilkan header `Content-Type: multipart/form-data; boundary=...` secara native dan otomatis.

2. **Optimalisasi `WhisperService.php`:**
   - Menambahkan pemetaan MIME type audio presisi (`webm` -> `audio/webm`, `wav` -> `audio/wav`, `mp3` -> `audio/mpeg`, dsb.).
   - Menetapkan nama berkas `voice.<ext>` yang valid pada objek `\CURLFile` untuk mencegah format file tidak dikenal pada Groq Whisper API.
