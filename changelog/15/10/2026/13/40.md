# Changelog — Refaktorisasi Arsitektur ke Model-View-Controller (MVC) Native PHP 8.4

- Waktu: 15/10/2026 13:40 WIB
- Fase: Arsitektur & Antarmuka Laragon
- Status: Selesai
- Terkait tugas: Refaktorisasi MVC dan pengaktifan Front Controller root http://ardenaai.test/

## Tujuan
1. Mentransformasikan struktur backend menjadi arsitektur **Model-View-Controller (MVC) Native PHP 8.4** yang modular, terstruktur, dan modern tanpa dependensi framework berat.
2. Memecahkan kendala domain Laragon `http://ardenaai.test/` yang sebelumnya menampilkan directory listing agar langsung menyajikan antarmuka workstation Tanya Ardena secara otomatis.
3. Memastikan seluruh kontrak API lama, suite pengujian, dan folder proteksi `Material/` tetap 100% kompatibel dan utuh (Zero Breaking Changes).

## Perubahan yang Dilakukan
1. **Core MVC Engine:**
   - Dibuat `Ardena\Core\Router` ([backend/src/Core/Router.php](file:///c:/laragon/www/ardenaai/backend/src/Core/Router.php)): Engine routing HTTP dinamis dengan normalisasi URI, parameter URL dinamis (`{id}`), dan dispatching action.
   - Dibuat `Ardena\Core\View` ([backend/src/Core/View.php](file:///c:/laragon/www/ardenaai/backend/src/Core/View.php)): Engine rendering tampilan dinamis berbasis PHP/HTML.
2. **Controller Layer:**
   - Dibuat `BaseController` ([backend/src/Controllers/BaseController.php](file:///c:/laragon/www/ardenaai/backend/src/Controllers/BaseController.php)) sebagai penyedia utilitas `json()`, `error()`, `view()`, `getPayload()`, dan `getAuthUser()`.
   - Dibuat `WebController` ([backend/src/Controllers/WebController.php](file:///c:/laragon/www/ardenaai/backend/src/Controllers/WebController.php)) untuk melayani view `chat` dan `riwayat`.
   - Dibuat `ChatController`, `VisionController`, `TranscribeController`, `ConversationController`, dan `HealthController` di [backend/src/Controllers/](file:///c:/laragon/www/ardenaai/backend/src/Controllers/).
3. **Model Layer:**
   - Dibuat `Conversation` ([backend/src/Models/Conversation.php](file:///c:/laragon/www/ardenaai/backend/src/Models/Conversation.php)) sebagai entitas representasi riwayat sesi obrolan siswa.
   - Dibuat `ScratchBlock` ([backend/src/Models/ScratchBlock.php](file:///c:/laragon/www/ardenaai/backend/src/Models/ScratchBlock.php)) sebagai entitas representasi blok Scratch 3 dengan pemetaan warna resmi Scratch.
4. **View Layer:**
   - Dibuat folder `backend/views/` berisi template dinamis [chat.php](file:///c:/laragon/www/ardenaai/backend/views/chat.php) dan [riwayat.php](file:///c:/laragon/www/ardenaai/backend/views/riwayat.php).
5. **Front Controllers & Routing:**
   - Dibuat rute master di [backend/src/routes.php](file:///c:/laragon/www/ardenaai/backend/src/routes.php).
   - Dibuat Front Controller utama di root: [index.php](file:///c:/laragon/www/ardenaai/index.php) dan [.htaccess](file:///c:/laragon/www/ardenaai/.htaccess) untuk domain `http://ardenaai.test/`.
   - Dibuat Front Controller publik di [backend/public/index.php](file:///c:/laragon/www/ardenaai/backend/public/index.php).
   - Memperbarui 8 file endpoint di [backend/public/api/*.php](file:///c:/laragon/www/ardenaai/backend/public/api/) sebagai delegator tipis ke Controllers untuk menjamin 100% backward compatibility.
6. **Pembaruan Dokumen:**
   - Memperbarui `Docs/Implementation_plan.md` pada Bagian 2 (Prinsip Arsitektur) dan Bagian 8 (Struktur Folder MVC).
   - Menambahkan catatan keputusan `D-008` pada `Docs/Decision_Log.md`.
   - Memperbarui status tugas pada `Docs/Task_Status.md`.
