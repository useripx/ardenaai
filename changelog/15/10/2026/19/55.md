# Changelog: 15/10/2026 - 19:55 WIB

## Ringkasan Perubahan
Penerapan **Dynamic Base Path Resolver** untuk mendukung arsitektur multi-host (`http://ardenaai.test/` dan subfolder `http://localhost/ardenaai/`), serta perbaikan krusial pada penanganan error audio transkripsi Groq Whisper yang sebelumnya memicu PHP Fatal Error (TypeError).

## Rincian Pekerjaan & Resolusi Bug
1. **Dynamic Base Path Resolver pada Views Frontend:**
   - Menambahkan helper `BASE_PATH`, `getApiUrl()`, dan `getPageUrl()` di `backend/views/chat.php`, `backend/views/riwayat.php`, `backend/views/pengaturan.php`, `backend/views/login.php`, dan `backend/views/daftar.php`.
   - Mengalihkan semua pemanggilan `fetch('/api/...')` menjadi `fetch(getApiUrl('...'))`.
   - Menambahkan dynamic rewrite untuk tautan navigasi `a[href^="/"]` agar otomatis berawalan `BASE_PATH` saat berjalan di subfolder.
   - Menggunakan dynamic import `await import((BASE_PATH || '') + '/js/firebase-init.js')` pada modul login & register agar tidak terkena 404 pada subfolder.

2. **Resolusi Fatal Error PHP pada Transkripsi Audio Whisper:**
   - Memperbaiki ketidaksesuaian tipe parameter pada `BaseController::error` dari `?array $details` menjadi `mixed $details` agar selaras dengan `ApiResponse::error`.
   - Memastikan `WhisperService::transcribe` selalu mengembalikan `$details` dalam format array `['raw' => $errorMsg]`.
   - Mengubah status code kegagalan transkripsi suara yang tidak jelas dari 500 menjadi 400 (Bad Request).

3. **Verifikasi Browser & Pengujian Otomatis:**
   - Pengujian live di Chrome DevTools pada `http://localhost/ardenaai/` dan `http://ardenaai.test/` membuktikan kedua host berhasil meresolusi endpoint secara otomatis.
