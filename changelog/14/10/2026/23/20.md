## Tujuan
Mengimplementasikan seluruh lapisan backend Ardena AI Scratch 3 berbasis PHP Native modern, menghubungkan layanan AI All-in-One Groq (Chat fallback 4 tingkat, Whisper STT, dan Vision qwen3.8-27b), middleware autentikasi Firebase, repository penyimpanan riwayat Firestore, validator blok Scratch 3, 8 endpoint API terstandarisasi, integrasi antarmuka frontend dari folder `Material/`, serta menjalankan uji otomatis komprehensif.

## Perubahan yang dilakukan
1. **Autentikasi & Otorisasi (Fase 3):**
   - Membuat `backend/src/Middleware/AuthMiddleware.php` dengan parser token JWT, verifikasi Google RS256 x509 certs, validasi kedaluwarsa (`exp`), dan dukungan dev token lokal (`dev_siswa_<uid>`).
2. **AI Chat & Auto-Fallback 4 Tingkat (Fase 4):**
   - Membuat `backend/src/Services/GroqService.php` dengan prompt sistem ramah anak SD dan transisi otomatis berurutan saat HTTP 429 (`openai/gpt-oss-120b` -> `qwen/qwen3.8-27b` -> `openai/gpt-oss-20b` -> `allam-2-7b`).
   - Membuat endpoint `backend/public/api/chat.php`.
3. **Validasi Blok Scratch 3 (Fase 5):**
   - Membuat `backend/src/Validators/ScratchBlockValidator.php` untuk memvalidasi kategori blok resmi Scratch 3 (Motion, Looks, Sound, Events, Control, Sensing, Operators, Variables), injeksi warna hex resmi, dan sanitasi XSS.
   - Membuat `backend/src/Validators/AIResponseValidator.php` untuk parsing respons JSON terstruktur (`answer`, `steps`, `blocks`, `follow_up_question`).
4. **Penyimpanan Riwayat Firestore (Fase 6):**
   - Membuat `backend/src/Repositories/FirestoreRepository.php` dengan kemampuan Cloud Firestore REST API dan fallback penyimpanan lokal per siswa di `backend/storage/conversations/{uid}/`.
   - Membuat 4 endpoint riwayat: `/api/conversations.php`, `/api/conversation.php`, `/api/conversation-save.php`, dan `/api/conversation-delete.php`.
5. **Analisis Gambar Groq Vision (Fase 7):**
   - Membuat `backend/src/Services/VisionService.php` menggunakan model multimodal vision Groq `qwen/qwen3.8-27b`.
   - Membuat endpoint `backend/public/api/vision.php` dengan pembersihan berkas gambar sementara otomatis setelah diproses demi privasi anak.
6. **Speech-to-Text Groq Whisper (Fase 8):**
   - Membuat `backend/src/Services/WhisperService.php` menggunakan `whisper-large-v3` Groq Audio Transcriptions API dengan prioritas Bahasa Indonesia (`language=id`).
   - Membuat endpoint `backend/public/api/transcribe.php` dengan pembersihan berkas audio otomatis.
7. **Integrasi Frontend Prototype (Fase 9):**
   - Membuat `backend/public/chat.html` yang mengadaptasi template asli `Material/stage_tanya_ardena_asisten_ai_scratch_3/code.html` dengan integrasi fetch live chat API, perekaman audio MediaRecorder, pengunggahan foto kodingan ke Vision API, dan render visual puzzle blok Scratch 3.
   - Membuat `backend/public/riwayat.html` untuk membuka dan mengelola sesi percakapan terdahulu.
   - Membuat `backend/public/index.html` sebagai titik masuk aplikasi.
8. **Pengujian Komprehensif (Fase 10):**
   - Membuat dan mengeksekusi `backend/tests/test_full_suite.php`.
   - Hasil: 18 LULUS, 0 GAGAL (100% PASS).
   - Menyusun `Docs/Test_Report.md` dan `backend/README.md`.
