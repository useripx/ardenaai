## Tujuan
Menyusun spesifikasi kontrak API lengkap sesuai template UI di folder `Material/`, membangun arsitektur fondasi backend PHP Native modern dengan PSR-4 autoloader mandiri, mengintegrasikan konfigurasi `.env`, menyiapkan helper responses, logging aman, wrapper HTTP client cURL, middleware CORS, serta memverifikasi endpoint `health.php` dan ketersediaan model Groq.

## Perubahan yang dilakukan
- **Dokumentasi Kontrak API:** Membuat `Docs/API_Contract.md` yang menetapkan spesifikasi 8 endpoint (`health`, `chat`, `transcribe`, `vision`, `conversations`, `conversation`, `conversation-save`, `conversation-delete`), format JSON standar, skema blok Scratch 3, dan kode error resmi.
- **Konfigurasi Environment:** Membuat `backend/.env.example` dan `backend/.env` yang memuat kunci `GROQ_API_KEY` dari `Docs/api`. Memastikan via Git bahwa `.env` terproteksi 100% oleh `.gitignore`.
- **Fondasi Backend:**
  - `backend/src/bootstrap.php`: Menginisialisasi autoloader namespace `Ardena\`, memuat `.env`, mengaktifkan logger, dan memproses header CORS.
  - `backend/src/Config/AppConfig.php`: Handler pembacaan variabel lingkungan berbasis PHP Native.
  - `backend/src/Support/ApiResponse.php`: Formatter respons JSON standar untuk respons sukses dan error.
  - `backend/src/Support/Logger.php`: Safe logging yang otomatis menyensor API key, token, dan kata sandi sebelum dicatat ke `storage/logs/`.
  - `backend/src/Support/HttpClient.php`: Wrapper cURL dengan timeout, retry handling, JSON parser, dan penanganan multipart.
  - `backend/src/Middleware/CorsMiddleware.php`: Handler CORS origin dinamis dan preflight `OPTIONS` 204.
  - `backend/public/api/health.php`: Endpoint pemeriksaan kesehatan sistem.
- **Pengujian Konektivitas & Model AI Groq:**
  - `health.php` teruji sukses `200 OK` dengan status `healthy` dan mendeteksi 11 model aktif di Groq.
  - Menguji ke-4 model fallback teks secara live:
    * `openai/gpt-oss-120b` (Priority 1) -> Sukses HTTP 200 (1354 ms).
    * `qwen/qwen3.8-27b` (Priority 2) -> Sukses HTTP 200 (621 ms).
    * `openai/gpt-oss-20b` (Priority 3) -> Sukses HTTP 200 (1121 ms).
    * `allam-2-7b` (Priority 4) -> Sukses HTTP 200 (866 ms).
  - **Temuan & Bukti Uji Vision:** Menguji `qwen/qwen3.8-27b` dengan gambar 100x100 warna biru Scratch -> Lulus sukses HTTP 200! Model ini terbukti multimodal vision-ready di Groq, mengenali warna blok Scratch dengan sangat presisi dalam bahasa Indonesia.
